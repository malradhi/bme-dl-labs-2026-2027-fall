## About this repository

This repository contains the practical laboratory materials for the MSc Deep Learning course at BME. The labs connect lecture concepts with programming, experimentation, and interpretation of results.

Materials are organised by lab. Each lab folder contains its own README, guided examples, and assignment notebook. New materials will be added during the semester.

The notebooks are available here and in the Moodle as well. Moodle is used for assignment submission.

## Learning goals

The laboratory sessions aim to help you:

- Translate deep learning concepts into working code.
- Prepare data and understand how it is represented in arrays and tensors.
- Build, train, and evaluate neural network models.
- Design experiments and interpret their results critically.
- Document your work so that another person can understand and reproduce it.

## How the labs work

Each session normally has three stages:

1. **Guided learning:** the instructor explains the concepts and works through examples with the class.
2. **Independent assignment:** students complete programming tasks and explain their results.
3. **Submission:** students check their work and submit the required files to Moodle.

Read the README and assignment instructions in each lab folder for its learning objectives, preparation, tasks, and submission requirements.

## Getting started

You will need a browser, an internet connection, and a Google account to work in Google Colab. Familiarity with basic Python, linear algebra, and derivatives will help you follow the exercises.

1. Open the relevant lab using the table above.
2. Read its README, then use the **Open in Colab** link for the required notebook.
3. Select **File → Save a copy in Drive** to create your own working copy.
4. Follow the lab's setup instructions and run the notebook cells in order.

No local Python installation is required when using Colab. Each lab specifies whether a CPU or GPU runtime is appropriate. For general help, see the [official Colab FAQ](https://research.google.com/colaboratory/faq.html).

## Assignment submission

Submit the files requested in each lab to Moodle by the stated deadline. For notebook assignments:

- Fill in the required student details in your own copy.
- Run the notebook from the beginning and check that your code, written answers, and required outputs are included.
- Follow the filename specified in the assignment.
- Download the executed `.ipynb` file and upload it to Moodle.
- Confirm that Moodle has recorded your submission.

A Colab sharing link alone does not replace the required notebook file.

**No Moodle access yet?** Keep a downloaded copy of your work and inform the instructor before the deadline so that a submission method can be confirmed. In this case, you must also send your work by email to the instructor.

## Academic practice

Work on your own submission and be prepared to explain your code and results. Follow the course rules for collaboration and AI tools, and record any assistance used.

Keep completed assignment answers and personal student details out of this public repository.

## Questions and updates
