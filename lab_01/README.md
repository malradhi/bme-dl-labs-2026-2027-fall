## Learning objectives

In this lab, you will learn to:

- Inspect and manipulate NumPy arrays, including shapes, indexing, and broadcasting.
- Standardise features using statistics calculated from training data.
- Use TensorFlow tensors, trainable variables, and automatic differentiation.
- Perform a parameter update and explain the roles of loss, gradient, and learning rate.
- Record experiments with TensorBoard and interpret loss curves.

## How the lab works

1. **Guided learning:** work through the examples with the instructor, discuss the results, and ask questions.
2. **Independent assignment:** complete the tasks in the assignment notebook, using the guided examples and official documentation as references.
3. **Submission:** check your notebook and submit it before the lab ends.

## Getting started with Google Colab

1. Sign in to your Google account and open a notebook using its **Open in Colab** button above.
2. Select **File → Save a copy in Drive** to create your own working copy.
3. Use a Python 3 runtime. **A CPU runtime is sufficient for Lab 1; no GPU is required.**
4. Run the setup cells first, then work through the notebook in order. Read the explanations as well as the code.

No local Python installation is required when using Colab. For help with saving and downloading notebooks, see the [official Colab FAQ](https://research.google.com/colaboratory/faq.html).

## Submitting Lab 1

1. Complete tasks **T1–T5** and fill in your name and Neptun code.
2. Restart the runtime and run all cells in order. Check that your written answers, printed results, and labelled loss plot are saved and visible.
3. Rename your notebook to **`YOUR_NEPTUN_DL_Lab01.ipynb`**, replacing `YOUR_NEPTUN` with your own Neptun code.
4. Select **File → Download → Download .ipynb** in Colab.
5. Upload the downloaded notebook to the Moodle assignment and confirm your submission **by the end of the lab**.

Submit the executed `.ipynb` file, not only a Colab sharing link. Submit your partial work on time if you cannot finish every task.

**No Moodle access yet?** Keep a downloaded copy of your work and tell the instructor before the lab ends so that a submission method can be confirmed.
